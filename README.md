# PCCOE Pune - Computer Engineering Research Portal & Indexing Audit

An executive institutional web portal and academic indexing intelligence platform for the **Department of Computer Engineering, Pimpri Chinchwad College of Engineering (PCCOE Pune)**.

Live Deployment: **[https://abhishekeb211.github.io/pccoe-research-portal/](https://abhishekeb211.github.io/pccoe-research-portal/)**

---

## 🌟 Highlights & Key Features

- **979 Verified Research Publications** across 89 Computer Engineering faculty members (2025–Present).
- **Academic Cycle Filtering**:
  - **Academic Year 2025–2026** (`July 2025 – June 2026`): 591 Papers (Institutional Accreditation Cycle).
  - **Post-June 2026 Momentum** (`July – October 2026`): 123 Papers (Q1 Fresh Momentum).
  - **Early 2025** (`Jan – June 2025`): 265 Papers.
- **Multi-Source Indexing & Quality Stratification**:
  - Official Scopus Sources Coverage (`scopus.com/sources`)
  - SCImago Journal & Country Rank (SJR) Quartiles (Q1, Q2, Q3, Q4)
  - Beall's List & Predatory Threat Sentinel (`beallslists.com`)
  - Springer Linked Open Data (LOD) & IEEE Xplore Conference Proceedings
- **Aesthetic Design**:
  - Pure white background (`#FFFFFF`) with tailored light pastel color palette.
  - Fully responsive across mobile, tablet, laptop, and ultra-wide displays.
  - Interactive Chart.js visualizations (SJR Quartile Donut Chart + Monthly Trend Bar Chart).
  - Dual view mode: Modern Card Grid and Spreadsheet Table view with instant CSV download.

---

## 🛠️ Tech Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3, Vanilla JavaScript (ES6+).
- **Visuals**: Chart.js (CDN).
- **Typography**: Google Fonts (Plus Jakarta Sans).
- **Deployment**: GitHub Pages.
